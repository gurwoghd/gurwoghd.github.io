This is an example note. Add a file named `YYYY-MM-DD-title.md` to `_posts/` and it will automatically show up in the notes list and get its own page.

## Regular markdown works

You can use standard markdown syntax.

```python
def hello():
    print("Code blocks are supported")
```

## Math support

MathJax is included by default, so math renders automatically.

Inline math: $E = mc^2$

Display math:

$$
\int_0^\infty e^{-x^2} \, dx = \frac{\sqrt{\pi}}{2}
$$

## Tags

Add `tags: [...]` to the front matter to show tags at the top of a note.
